# 测试说明（step2_wlan 局域网/多项目/RBAC 等改造）

本目录记录本轮改造的**单元测试、测试用例、特殊/边界场景**与**测试报告**。
测试基于 Node 内置 `node:test`（零第三方依赖），覆盖后端纯逻辑、I/O 集成、以及前端纯判断逻辑。

## 一、如何运行

```bash
# 后端（gateway）：单元 + mock + 集成（含模拟两台网关的中央转发）
cd gateway && npm test

# 前端纯逻辑（web-dashboard）
cd web-dashboard && npm test
```

> 集成测试会临时启动隔离的网关子进程（用临时配置/端口 39101/39102/39201），跑完自动结束，不影响真实数据与端口。

## 二、可测性设计

为隔离测试数据、不污染真实配置/密钥，给三处加了**仅测试用的环境变量覆盖**（生产零影响）：

| 模块 | 环境变量 | 作用 |
|------|---------|------|
| `services/config.js` | `GATEWAY_CONFIG_PATH` | 网关配置文件路径 |
| `services/devbench/store.js` | `DEVBENCH_CONFIG_PATH` / `DEVBENCH_STORE_DIR` | 共享配置 market-projects / 运行时存储目录 |
| `services/admin-totp-store.js` | `ADMIN_TOTP_DIR` | 超管 TOTP 密钥目录 |

## 三、覆盖范围与测试用例

### 1. TOTP 超管验证码（`gateway/test/totp.test.mjs`，8）
- **标准向量**：RFC 6238 官方测试向量（T=59/1111111109/1234567890/2000000000）逐一比对。
- **base32**：解码正确、忽略大小写/空格/padding；密钥随机性与字符集。
- **时间窗**：±1 步（前/后 30s）容忍通过，±3 步拒绝。
- **边界/异常**：空、null、非 6 位、非数字、带空白码。
- otpauth URL 结构。

### 2. 共享配置 store（`store.test.mjs`，10）
- **仓库定义**：空配置回退 3 种子；只填 https/ssh **自动补全另一个**；**仓库名/git 地址双去重**；删除。
- **车型多工程映射**：`apps→展平 entries` + **按项目隔离**；**旧三代结构迁移**（顶层 `appMarketBranch/needWebApp/...` → `byProject.apps/entries`）。
- **关键词映射**：同步**补新 key 且保留已有映射**、按项目隔离；删除；**标题识别**应用/车型。
- **旧顶层数据迁移**：顶层 `vehicleMap`/`keywordMappings` → 默认项目桶 `byProject`。
- **克隆父路径**：全局（跨项目共享）+ 默认值。

### 3. Teambition 纯逻辑（`teambition.test.mjs`，7）
- **标题关键词提取**：全角 `【】`、半角 `[]`、混合、去重、嵌套空括号忽略；无括号/空/null/undefined。
- **TB 项目列表**：配置驱动；空配置**回退旧默认**（平台组件）；过滤无 id 脏项。

### 4. 管理后台鉴权（`admin-auth.test.mjs`，9）
- **token**：签发→校验→吊销；无效/空 token 返回 null。
- **requireAuth 中间件**：无 token→401；角色不符→403；符合→next 且注入 principal。
- **超管 TOTP 登录**：正确码通过/错误码拒绝；首登标记 enrolled；**密钥重置后旧码失效**。
- **非名单用户拒绝**：钉钉/TB 用户不在 admin_users → 拒绝并回带已识别身份。

### 5. 环境诊断/仓库权限（`env-diag.integration.test.mjs`，5，集成）
- **env-check**：返回结构 + 必需项(git/java)标记 + `okToCompile`/`hasWinget` 布尔，与本机实际一致。
- **env-install**：未知工具→拒绝（不真正触发 winget 安装）。
- **repo-access**：未知仓库→错误；**无法访问的仓库（git@127.0.0.1 无凭证）→ hasAccess=false**（无需真实凭证即可验"无权限"路径）。
- **admin-contacts**：返回管理员数组（结构含 name/dingUserid）。

### 6. 局域网中央转发（`forward.integration.test.mjs`，6，集成）⭐
**模拟两台网关**（无需多台物理机）：`server`(standalone 权威) + `node`(role=node，host 指向 server)。
- node 读**仓库定义/车型映射/关键词映射 = server 的**（转发，非本地种子）。
- node 的 **cloneParent 用本机**（不取 server 的）。
- **env-check 始终本机**执行。
- server 自身权威（standalone 不转发）。

### 7. 前端纯逻辑（`web-dashboard/src/pages/devbench/diaglogic.test.mjs`，6）
组件与测试共用 `diaglogic.js`（无 React/DOM 依赖）：
- `envMissingRequired`：列出缺失的**必需**工具（可选项不计入）；空/异常输入。
- `envOkToCompile`：必需全装→true，缺一→false，无必需项→true。
- `toolAction`：已装 none / 有 winget install / 无 winget manual。
- `recoText`：应用+车型 / 只一个 / 都无 / null 的文案。
- `apiQuery`：projectId/refresh 组合 + URL 编码。

## 四、特殊/边界场景清单

- 编码：全角/半角括号、URL 编码、空格/大小写。
- 空值：null/undefined/空串/空数组/脏项。
- 冲突：仓库名重复、git 地址重复。
- 时间：TOTP ±1 时间窗、超窗拒绝、密钥重置后旧码失效。
- 越权：无 token / 角色不符 / 非管理员名单。
- 数据迁移：旧三代车型结构、旧顶层 vehicleMap/keywordMappings → 按项目桶。
- 隔离：多项目下车型/关键词互不影响。
- 局域网：node 转发读 server 共享配置、cloneParent 留本机、env-check 留本机（用集成测试真实验证）。
- 无凭证验"无权限"：用不可达 git 地址触发 ls-remote 失败。
