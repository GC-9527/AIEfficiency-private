# 交互规范

## 导航

- 一级导航切换更新 URL 语义、标题和左侧选中态。
- 工作台二级 Tab 保留筛选和滚动位置。
- 批次详情、配置审核和设置子页使用面包屑。
- `Esc` 依次关闭 Popover、Dialog、Drawer。
- 打开 `/devbench` 使用新标签，不替换工作台上下文。

## 新建故事点

### 输入

- 点击“新建故事点”打开 960px 大 Drawer。
- 智能输入按换行拆分；TB 模式还支持空格、中英文逗号和分号。
- 输入 1 条走单任务向导；大于 1 条可直接转批量处理中心。
- 超过 100 条阻断，并显示“只保留前 100 条”与“返回编辑”。

### 识别

- 识别后先生成 Task Draft，不显示已创建。
- 每行可编辑、移除或重新识别。
- 汇总显示总数、有效、重复、无效、已有故事点、可创建。
- 自然语言 Git Review 如果缺仓库/Base/Head，状态为“需要确认”。

### 推导

- Mock 进度显示正在处理的字段和证据来源类别。
- 不展示模型内部思维链。
- 用户可暂停 Demo 推导；暂停只影响未开始项。

### 配置审核

- 左列为 AI 推荐，只读。
- 右列为最终配置，可编辑。
- “全部采用”只采用有效且未被用户锁定的字段。
- “忽略 AI”清空未锁定推荐，并暴露必填阻断。
- 每字段支持采用、修改、清空、锁定、解锁和查看证据。
- 修改主工程会重新计算可选仓库和 Flavor；不自动覆盖用户锁定值。

### 预检与确认

- 修改关键字段后 400ms 防抖执行 Mock 预检。
- 阻断禁止继续；警告允许用户确认后继续。
- 点击问题可定位字段。
- 最终确认明确“以下配置将传递给故事点创建和后续工作流”。

## 批量处理

- 默认打开“仅查看异常项”。
- 自动通过任务折叠，只在状态分布和展开视图中出现。
- 选中行后出现 Sticky 批量操作条，明确影响数量。
- 公共字段批量应用前必须预览继承、跳过和覆盖行为。
- 目标分支默认是每任务独立字段，不允许被公共设置覆盖。
- 创建所有已就绪后显示：创建成功、创建失败、正在执行、等待执行。

## 自动修复和候选版本

- 最多 3 次，版本为 V1/V2/V3。
- 每次结束更新评分、关键字段最低分、阻断和警告。
- 如果新版本评分下降，不自动替代历史最佳。
- 回滚按钮文案为“恢复为最佳候选”，确认 Dialog 明确“不会执行 Git 回滚”。
- 达到上限自动转人工介入。

## 人工介入

- 默认折叠已通过字段。
- 第一屏只展示阻断和低可信关键字段。
- 字段预填最佳候选、历史成功值和推荐候选。
- 用户修改后立即 Mock 预检。
- 通过后自动进入已就绪并关闭 Drawer，可在 Toast 中撤销 5 秒。

## 表格

- 表头 Sticky。
- 第一列选择框和任务摘要列固定。
- 横向滚动时关键列保持可见。
- 每行只有一个主要按钮。
- 次要操作使用文字按钮，低频操作进入 More Menu。
- 点击行打开 Drawer；点击按钮不触发行选择。

## Drawer

故事点详情页签：

1. 概览
2. 工作流
3. 执行配置
4. 操作记录
5. 异常
6. 报告

Git Findings Drawer 默认打开 Critical/Major，Minor 折叠。

## 设置

- 修改后顶部出现“有未保存修改”。
- 离开设置页弹出保存/放弃确认。
- 降低并发到当前运行数以下时显示说明，不终止当前任务。
- 保存设置立即更新 Demo 的并发数字和批量分流。
- 恢复默认需要二次确认。
- 重置 Demo 只重置本地 Mock 状态。

## 反馈

- 所有主要按钮提供 Toast、状态变化、Drawer/Dialog 或 Mock 进度。
- 危险操作使用确认 Dialog。
- Disabled 按钮使用 Tooltip 说明原因。
- 长操作提供可取消 Mock Loading。
- 部分失败保留成功项，并允许只重试失败项。

## 键盘与可访问性

- `Tab` 顺序与视觉顺序一致。
- Focus 使用 2px 蓝色外环。
- `Enter` 激活主按钮；`Space` 选择表格行。
- Drawer 和 Dialog 打开后锁定焦点。
- 状态由图标、文字和颜色共同表达。
- 表单 Label 与错误通过 `for`/`aria-describedby` 关联。
