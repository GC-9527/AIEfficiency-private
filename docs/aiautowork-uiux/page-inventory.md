# 页面与界面清单

## 一级页面

| 页面 | 页面目标 | 核心模块 | 主要操作 |
|---|---|---|---|
| 工作概览 | 5 秒内识别当前压力和最紧急事项 | 并发、等待人工、异常、即将执行、最近批次 | 新建、处理异常、进入 DevBench |
| 故事空间 | 保留 DevBench 故事点 Tab 心智 | 左侧故事导航、最近上下文、运行摘要 | 切换、关闭、恢复、进入故事点 |
| 进行中 | 管理运行、排队、暂停、阻塞 | 高密度表格、状态筛选、详情 Drawer | 暂停、继续、处理配置 |
| 待办队列 | 管理尚未或等待执行的任务 | 队列位置、优先级、来源、下一步 | 调整队列、创建故事点、移除 |
| 代码评审 | 统一 Review 任务 | Review 类型、Base/Head、Findings | 查看 Findings、处理确认、重试 |
| TB 需求池 | 聚合多个 TB 来源并去重 | 来源标签、TB 状态、故事点关联 | 创建、加入待办、打开 DevBench |
| 执行记录 | 查询历史结果 | 时间、来源、结果、报告 | 查看报告、重新执行 |
| 批量处理中心 | 管理全部批次 | 批次状态、总数、异常、创建结果 | 打开批次、暂停、重试 |
| 批次详情 | 只处理异常和组确认 | 状态分布、紧凑表格、批量操作 | 批量补全、按组确认、创建已就绪 |
| 配置待确认 | 集中处理配置异常 | 阻断、低可信、多次失败、批量分组 | 处理配置、批量补全 |
| 工作台设置 | 设置执行与推导策略 | 分类设置导航、未保存提示 | 保存、取消、恢复默认、重置 Demo |

## 新建流程界面

| 界面 | 形式 | 说明 |
|---|---|---|
| 新建故事点 | 960px 大 Drawer | 统一入口，包含 5 种输入模式 |
| 智能输入 | Drawer Step 1 | 混合内容逐行识别 |
| TB 输入 | Drawer Step 1 | 支持多种分隔符和链接 |
| 手工任务 | Drawer Step 1 | 标题、描述、优先级、标签、模式 |
| Git Review | Drawer Step 1 | Commit/Range/Branch/MR/自然语言 |
| 批量输入 | Drawer Step 1 | 最多 100 条，超过阈值进入批次 |
| 输入解析预览 | Drawer Step 2 | 有效、重复、无效、已有故事点 |
| AI 推导中 | Drawer Step 3 | Mock 并发进度，不显示思维链 |
| AI 候选配置 | Drawer Step 4 | 推荐值、来源、可信度、证据摘要 |
| 推荐与最终对比 | Drawer Step 4 | 逐字段采用、修改、忽略、锁定 |
| 主工程选择 | 大 Popover / 子 Drawer | 最近、推荐、收藏、业务域 |
| 主仓库选择 | 子 Drawer | 工程和仓库分离 |
| 依赖工程 | 可编辑表格 | 每仓库独立分支和权限 |
| Flavor 配置 | 结构化选择器 | 目标、影响、回归、Variant |
| 配置完整度 | Sticky 侧栏 | 必填、条件必填、未确认、警告、阻断 |
| 配置预检 | Drawer Step 5 | 跳字段、自动修复、必须人工 |
| 最终确认 | Drawer Step 6 | 明确传递给故事点创建的配置 |
| 创建结果 | Drawer Step 7 | 创建、排队、运行分别统计 |

## 批量与配置界面

| 界面 | 形式 | 说明 |
|---|---|---|
| 配置分组确认 | 920px Dialog | 公共字段和每任务差异分开 |
| 批量人工补全 | 840px Dialog | 显示影响数量和继承规则 |
| 候选版本历史 | 右侧 Drawer Tab | V1–V3 评分、差异、最佳候选 |
| 自动修复中 | 批次行状态 + Drawer | 最多 3 次，可暂停 |
| 回滚最佳候选 | Confirm Dialog | 明确不是 Git 回滚 |
| 人工介入 | 配置 Drawer | 只突出异常字段 |
| 故事点详情 | 720px Drawer | 6 个页签 |
| Git Findings | 760px Drawer | Critical/Major/Minor 分组 |
