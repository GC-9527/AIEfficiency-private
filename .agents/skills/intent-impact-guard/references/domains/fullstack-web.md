# 全栈 Web、登录、路由与 UI 检查表

## 登录入口

用户说“没有登录入口”时，按顺序检查：

1. 是否已有 `/login`、SSO、扫码或认证弹窗；
2. 首页、顶部导航、用户菜单、受保护路由是否暴露入口；
3. 客户端路由守卫与服务端鉴权是否同时存在；
4. 登录成功、失败、过期、退出、刷新、深链回跳；
5. 管理后台是否已有独立业务职责和权限；
6. 多租户、管理员/普通用户、浏览器独立身份是否受影响。

安全默认：保留业务路由，新增或暴露独立认证入口；未登录访问时带安全校验的 `redirect` 返回原目标。校验 redirect，防止开放重定向。

禁止：把 `/admin`、首页或业务页面改成登录页；只在前端隐藏后台；用默认管理员身份绕过认证；把扫码会话变成全浏览器共享会话。

## 路由与权限

- 路由名称、URL 语义、书签和刷新兼容；
- 前端守卫仅用于体验，服务端仍必须授权；
- 401 与 403 语义区分；
- 登录后回跳不能跳到未授权页面；
- 角色切换、会话过期、并发标签页状态；
- SSR/CSR、API Gateway 和反向代理路径前缀。

## UI 关联影响

修改共享 UI 前检查：

- 所有引用点和变体；
- 容器宽高、flex/grid、overflow、z-index、position；
- loading/error/empty/success；
- 320px、常用桌面宽度、超宽屏和缩放；
- 键盘焦点、Tab 顺序、可访问名称；
- 深色/浅色主题、国际化长文本；
- 弹窗、抽屉、下拉、sticky/fixed 与状态栏。

验证目标页面之外至少一个代表性关联页面。不能用绝对定位或提高 z-index 暂时掩盖结构问题。

## 前后端合同

- API、字段、错误码、分页、幂等和版本；
- 前端 Mock 与真实后端保持同一接口；
- 缓存失效、竞态、取消请求和重试；
- 后端权限不能依赖前端字段；
- 新入口不得泄露内部路由、用户信息或调试接口。
