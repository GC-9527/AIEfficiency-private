# 不变量目录

不变量不是泛泛的“不要出问题”，而是可由证据和测试验证的行为合同。

## 通用不变量

| 不变量 | 常见证据 | 验证方式 |
|---|---|---|
| 页面/路由职责不变 | 路由表、页面组件、产品文档 | 直接访问、导航、刷新 |
| 权限不降低 | 守卫、中间件、角色映射 | 未登录/低权限/高权限矩阵 |
| 公共合同兼容 | API 定义、接口、AAR/npm 包 | 编译调用方、契约测试 |
| 单一源码 | Gradle/npm/workspace 依赖、模块图 | 重复文件扫描、依赖解析 |
| 无关改动不受影响 | Git status/diff | diff 范围检查 |
| 失败路径保持 | 异常处理、错误码、回退逻辑 | 失败注入、断网/空数据 |
| 可回滚 | Git/迁移方案/feature flag | 回滚演练或逆向操作 |

## 登录与管理后台

- `/admin` 仍表示管理业务，而不是认证页面；
- 未授权用户不能看到后台数据；
- 登录成功后能返回原始目标；
- 登录失败、会话过期、刷新和退出行为保持正确；
- 新增入口不能绕过服务端授权。

## Mock、调试和测试能力

- 生产数据源变更不隐式删除 AppMock；
- Mock 与生产实现通过接口/注入切换，而不是复制业务逻辑；
- debug/test 能力不会进入不应发布的生产包；
- 自动化测试依赖的入口、命令和协议保持可用。

## SDK 与公共 API

- `sdk-api` 只定义稳定合同；厂商实现位于唯一 `sdk-xxx-impl`；
- 应用市场工程不得保存第二份 SDK 源码；
- 车型共享同一实现时，通过配置/适配层区分，不复制工程；
- 版本号、第三方 libs、ProGuard/R8、ABI 和内存生命周期合同保持；
- 文档、截图、日志和接入资料与对应机型目录一致。

## UI/UX

- 共享组件改动不能导致其他页面挤压、遮挡、溢出或焦点丢失；
- 键盘、屏幕阅读器、缩放、暗色模式和断点行为保持；
- loading/error/empty/success 状态完整；
- 不用隐藏或覆盖元素掩盖逻辑问题。

## Android/KMP

- 生命周期、协程取消、监听器和 Context 引用不新增泄漏；
- 主线程不增加阻塞 I/O；
- 配置变化、进程重建、多 Display 和车机生命周期行为保持；
- `commonMain`、平台 source set 与 Flavor 的职责不混淆；
- 资源、Manifest、ProGuard 和打包变体保持一致。

## 多 AI 协作

- Root Agent 持有目标、架构、风险和最终验收；
- Worker 不改变已批准方案和模块边界；
- 共享工作树同一时间最多一个可写 Agent；
- 交接绑定 branch、HEAD、Dirty Patch、Variant/Flavor 和证据；
- 旧 AI 的推断不是事实，接手者必须重新核对动态状态。
