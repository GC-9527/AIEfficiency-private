```markdown
- 方案：

```

## 规则

- 只有实际执行且退出成功的项可写 PASS。
- 浏览器或服务不存在时写 SKIPPED/INCOMPLETE，并说明如何补齐。
- 基线本身失败时标记 BASELINE_FAIL；本次没有新增不等于整体健康。
- 失败结果不得通过普通 `--update-baseline` 被覆盖；经批准的包体预算例外必须记录 `--accept-budget-change` 原因。
- 浏览器几何、视觉、页面、安全或测试失败不存在“更新基线即通过”的例外。
- 截图、JSON、日志使用相对仓库路径，避免泄露本机绝对路径。
- 用户可见短评可简化，但仓库内报告必须保留真实证据。
